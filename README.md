# Bridgeway, a design concept

A product design concept for Adobe's Project Bridgeway, by Gauravi Linjara.

Onboarding rebuilt as a translation layer: five questions in the owner's own
language, then useful work prepared for their review. Static HTML, no build step.

- `index.html` — the case study
- `assets/bridgeway/flow/` — prototype screens
- `assets/bridgeway/deck/` — imagery from the pitch deck
- `assets/bridgeway/plate-*.jpg` — plates from the overnight film

The companion film lives at https://bridgeway-mu.vercel.app
